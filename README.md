### 🔭 What I work on
- **Graph AI for coordinated fraud:** temporal graph neural networks that detect fraud rings hidden across cards, devices, and merchants
- **Explainable AI for regulated domains:** models whose decisions analysts and auditors can review
- **Healthcare payment integrity:** anomaly detection for U.S. Medicaid billing and Electronic Visit Verification (EVV)
- **Production engineering:** real-time APIs, data pipelines, and full-stack platforms

### 🚀 Featured projects

**[FinGuard-XAI](https://github.com/sibbirhossain/finguard-xai)**: real-time, explainable graph AI for payment fraud
- Temporal GNN + dual-channel novelty alerting for **previously unseen** fraud patterns
- 5-seed evaluation, adversarial-robustness study, drift monitoring, **~5 ms** per-transaction scoring
- FastAPI service · React dashboard · Colab notebooks · preprint · archived on Zenodo

**[MedicaidGuard-XAI](https://github.com/sibbirhossain/medicaidguard-xai)**: explainable ML for Medicaid fraud detection and EVV
- End-to-end pipeline on real CMS data with statistically validated results and explainable outputs
